## Implemented surface behavior

`/admin/studio/writing` lists actual projects with state, version, save time, pagination and an empty-state link to reviewed topics. `/admin/studio/writing/:id` identifies one manuscript and offers a separate browser window. The editor keeps Pure Spoken, Production Plan and Materials/Notes distinct, with a Tiptap toolbar or Markdown text view. Save status is sticky; changes wait two seconds before autosave, and manual save remains available. Unsaved text prompts before leaving. An unconfirmed save, network failure or stale version retains local edits, blocks unsafe follow-up actions and offers retry/server comparison.

Recovery storage has an independent UUID for each editor window. Opening the same project discovers its recoverable copies and presents their base version, timestamp and excerpt in a native select. Restore first copies text into the current window's record; using the server version for this visit does not discard another window's copy. Only the explicitly selected discard action removes that copy. A recovery based on an older server version requires comparison rather than silent overwrite.

The support area shows per-project instructions, generation/proposal/failure state, model-disabled explanation, model-check caveat and estimated duration; frozen sources retain fact/expression/counterpoint roles and saved Skill text/versions. History displays total/page and newer/older links through `historyPage`, including versions beyond the first 30. Selecting a historical version leaves editing content unchanged; restoring creates a new draft while confirmed snapshots remain. Explicit confirmation is distinct from autosave and text export.

Copy uses the current rendered view as ClipboardItem HTML and plain text when supported, with a clear fallback; Markdown mode copies its current text. Single-view Markdown export remains a draft and does not confirm the manuscript. The subsequent image/ZIP extension adds private user-uploaded static images, paste-image editing and version-bound offline ZIP download; standalone offline HTML and automatic source-image collection remain incomplete.
